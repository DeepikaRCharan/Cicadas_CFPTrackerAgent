# Examples

Output from one live rehearsal run on 2026-10-09 (06:24 UTC), for the `ai-tutoring` profile, run against a scratch tracker with `python -m src.run --demo`.

- [`rehearsal-run.md`](rehearsal-run.md): the demo view of the run, in four sections (reading the paper, searching, verifying, scoring), then a results table and the cost.
- [`rehearsal-trace.md`](rehearsal-trace.md): the full discovery trace of the same run. It covers every search and fetch with the model's stated reason, every verdict and the code's reply, the verified deadline quotes, each venue's extracted facts, and every fit score with its reasoning.

The paper behind the profile is Kestin et al., "AI tutoring outperforms in-class active learning: an RCT introducing a novel research-based design in an authentic educational setting", *Scientific Reports* (2025). It is real, published research, not the repo author's own work. It is used here only to exercise Cicadas.
